# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | Yes                |

## Reporting a Vulnerability

If you discover a security vulnerability within `env-check`, please report it responsibly.

Do not create public GitHub issues for security vulnerabilities. Instead, please report them via GitHub Security Advisories at:

https://github.com/YusufBeratZengin/env-check/security/advisories/new

Alternatively, contact the maintainer directly at `118852217+YusufBeratZengin@users.noreply.github.com`.

Please include the following details in your report:
- Type of issue (e.g. secret leakage, regex denial of service, improper path handling)
- Full steps to reproduce the issue, including sample configuration or commands
- Expected behavior versus actual observed behavior
- Proof of concept or minimal reproduction repository

We will acknowledge receipt of your report within 48 hours and provide status updates as fixes are prepared.
